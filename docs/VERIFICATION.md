# Результаты проверки

Проверка: 8 ноября 2026 года. Runtime: Node.js v22.16.0. Workflow настроен на Node.js 24.

## Выполнено

`npm run test:native`: **57 passed, 0 failed, 0 skipped**. Это самостоятельные проверки `node:test`, не переименованный запуск Vitest.

Проверены реальные HTTP-запросы GET/POST, требуемая разметка, UTF-8, Content-Length, 400/404/405/413/500, повторяющиеся поля, экранирование HTML, chunked-запросы, граница 16 KiB, оборванное соединение, параллельные запросы и запуск экспортированного сервера. Дополнительно проверена раздача собранного сайта под /repository-check/.

Скриншот реального вывода: [tests-native.png](tests-native.png). Текст: [tests-native.txt](tests-native.txt).

Сборка `npm run build` и проверка синтаксиса/JSON `node scripts/check.mjs` завершились успешно. 

HTML/CSS визуально проверены в Chromium при ширине 1440 и 390 px; горизонтального переполнения нет. HTML получен реальными запросами к работающему серверу и передан в DOM браузера. Для статической формы отдельно выполнены DOM-проверки успешного ввода, безопасного вывода HTML-подобного текста и отклонения пробельного имени.

## Не подтверждено в этой среде

`npm install` не завершился: DNS-ошибка `EAI_AGAIN` для `registry.npmjs.org`. Поэтому **9 исходных Vitest-тестов** и покрытие Vitest здесь не запускались. Исходные тестовые файлы сохранены побайтно.

Chromium блокирует переходы к localhost и файловым адресам с `ERR_BLOCKED_BY_ADMINISTRATOR`. Подготовлен воспроизводимый `npm run test:browser`, но полный навигационный браузерный прогон здесь не подтверждён. Визуальная/DOM-проверка не выдаётся за этот прогон. Скриншоты Vitest не подставлялись вместо реальных результатов: `npm run test:report` создаёт их после настоящего запуска.

Репозиторий и опубликованный Pages-сайт не создавались. Для проверки публикации необходимо выполнить workflow в собственном репозитории.
